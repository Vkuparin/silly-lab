# Whack-a-Mole 1.0.0

A complete offline mouse-practice arcade game, with a gentle starting point and more ways to play together.

## New

- Untimed Practice with four large targets or nine holes, picture instructions and five-click goals.
- Garden's short gentle rounds and guaranteed golden surprises; Harvest's two-target play, star visitors and small combo rewards.
- Original Classic scoring and five-level speed ramp retained.
- Pass-the-mouse Family matches for 2–4 players: identical full-round Garden schedules, optional per-player pace, joint winners and rotating-order rematches.
- Six local avatar profiles, eight collectible stickers, personal bests and pace/input-specific top-10 records.
- Illustrated characters, layered Garden/Snow/Space scenery, redesigned menus/results, local score feedback and reduced motion.
- Responsive displays through 5120×1440 ultrawide; native startup sizing fits the monitor work area.
- Explicit pause/resume, focus-loss/scheduling-gap pause, optional keyboard play, independent audio volume and complete EN/FI UI.
- Main-menu and Settings **Exit game** button, including native fullscreen; fullscreen toggle also included.

## Compatibility and data

Classic still replaces moles on its timer even when they are not clicked. New pointer press/release validation and a short double-click grace improve single-click practice. Changed pace or mixed gameplay input produces an unranked result; keyboard menu use alone does not.

Old scores remain readable as Legacy, without guessing their difficulty. Existing language/audio/pace preferences persist. New data is validated, bounded and safe against corrupt/future schemas; failed saving is visibly session-only. Portable mode retains its adjacent `data` folder when `portable.txt` is beside the executable.

## Downloads

- Portable ZIP: `whackamole-1.0.0-win-x64.zip`
- NSIS: `whackamole_1.0.0_x64-setup.exe`
- MSI: `whackamole_1.0.0_x64_en-US.msi`
- Checksums: `SHA256SUMS.txt`

Windows x64 and Microsoft Edge WebView2 Runtime are required. Portable ZIP does not bundle WebView2; installers can download its bootstrapper when needed. Gameplay is offline afterward. Packages are unsigned. Extract portable files into a writable folder and keep the marker/data together.
