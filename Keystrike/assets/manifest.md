# Asset provenance

- `icon.svg`: original Keystrike cannon/beam artwork created for this project; raster/ICO variants generated by the pinned Tauri icon command.
- `src/render.ts`: original procedural pixel artwork: Helsinki-inspired waterfront, cathedral, cranes, islands, moon, aurora, cannon skins and twelve commander silhouettes. No external images or font files.
- `src/audio.ts`: original synthesized oscillator melodies, boss motif and effects. No samples or prerecorded music.
- `docs/screenshots/*.png`: captures of the running game by the repeatable UI smoke script. These show actual UI, not concept art.

Project assets use the project MIT license. Segoe UI/system monospace fonts are supplied by the player's operating system and are not redistributed. Rendering/assets have no runtime network dependency.
