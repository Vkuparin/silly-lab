# Keystrike v0.1.0 — first playable release

Defend Helsinki with a personal waterfront cannon. Twelve missions in Keyboard, Mouse and Mixed tracks include ordinary waves, a miniboss and a named commander. Finnish/English UI, finger rehearsal, Standard/Relaxed/Pro/Practice, local scores, stars, salvage and fourteen cosmetic upgrade tiers are included.

- Keyboard teaches F/J home position through the home row, three rows, profile-specific punctuation and named keys. Mixed has its own WASD-area curriculum.
- Pro unlocks per completed level. Keyboard/Mixed L11–12 use one/two release-separated left-Shift sequences; mouse Pro stays mouse-only. Primary-only and any-Shift profiles are available.
- Mistakes reset streak without hurting the city. Focus loss, resizing and large frame gaps pause; missed threats consume one shield. Surviving a commander escape unlocks the next lesson without a commander kill reward.
- Save or Skip on every result. Optional nicknames, separate top-ten boards, restart persistence, backup export/import and independent resets.
- Original pixel waterfront, twelve commander silhouettes, cannon/beam customization and synthesized chiptune audio. Calm and reduced-motion settings override spectacle.

## Downloads and portability

Windows x64. Extract the portable ZIP into a **writable** folder and run `Keystrike.exe`; the separate EXE contains the same game. Microsoft Edge **WebView2 Runtime is required and is not bundled**. No game installation, account or runtime content download.

All Keystrike-owned saves **and WebView2 cache/profile** stay in `data/` next to the EXE. No marker, no AppData fallback. Keep/move the entire folder to preserve progress. Read-only startup reports an error instead of writing elsewhere.

## Validation and current limits

231 content/core/storage checks cover the full track/preset/layout campaign matrix, pair boundaries, escapes, scoring, transactions and recovery. Strict TypeScript/frontend and Windows release builds pass. UI/native smoke evidence and screenshots are recorded in the repository's `Keystrike/docs/verification.md`.

This is a playtest release. School-laptop performance, supervised beginner learning/fun, and real FI/US layouts with Sticky/Filter Keys still need human/device testing. Synthetic tests establish game rules, not educational efficacy or OS shortcut behavior. Use Standard/Relaxed or the appropriate accessibility profile when Shift delivery differs. Timing/prices/flavor remain initial tuning values; fast automated play can finish early levels below the draft's human-session target.

Unsigned Windows executable; no installer/runtime bundle or non-Windows build is promised. See `Keystrike/AGENTS.md` for the preserved development/release workflow.
