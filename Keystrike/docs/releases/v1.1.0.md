# Keystrike v1.1.0

- **Fixed next-level Pro lock:** completing a Pro replay continues in Standard if Pro is locked on the next level. Already-unlocked Pro remains Pro, using the finished attempt's route.
- **Clearer results action:** Next level is highlighted after success when the next level is still unbeaten. Replay stays available with its independent difficulty selector.
- **Main-menu Exit:** localized Exit/Lopeta closes the native game, including fullscreen, and supports Tab/Enter. The home top bar no longer shows the difficulty badge.
- **Longer combat:** both campaigns and all presets have 50% more wave time and approximately 50% more miniboss/commander hits or words, rounded up. The final king still ends with one seeded sentence. Deadlines account for the added work; regular-ship travel, spawn pressure, phases and cosmetic fairness stay consistent.

Keep your existing `data/` beside the EXE when replacing it. Save schema 2 preserves progress, ownership, currency and old Highscores. New content uses comparison tuple 3.2.3, separate from older boards. All game-owned persistence and WebView2 cache remain beside the EXE; no AppData fallback.

Windows x64, unsigned standalone EXE or portable ZIP. Microsoft WebView2 Runtime is required separately. See [verification](https://github.com/Vkuparin/silly-lab/blob/keystrike-v1.1.0/Keystrike/docs/verification.md) for automated/browser/final-package checks. Human pacing/impact, school-laptop performance and physical vendor/accessibility input compatibility remain playtest work.
